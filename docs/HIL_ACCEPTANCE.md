# 实机验收计划与记录模板

当前状态：**H01、H02、H03全部 NOT_RUN**。本次软件测试没有打开真实串口、配置GPIO、启动daemon或执行运动。以下是后续取得用户明确实机授权、补齐设备资料后的验收步骤；不得把本文、仿真曲线或测试替身的返回值当成实机通过记录。

## 验收前提

先阅读 [硬件接线](HARDWARE_WIRING.md)、[SDK迁移](SDK_MIGRATION.md) 和 [配置标定](CONFIGURATION_AND_CALIBRATION.md)。配置只能来自实际设备记录；不要把simulation.yaml复制成hardware并只翻转一个verified标志。

每次运行记录：日期和操作者、授权范围、机械载荷和允许行程、设备型号/序列号/固件、接线版本、软件构建标识、配置和标定版本、仪器型号/校准、原始数据文件位置、预设通过阈值。缺阈值时只能做探索实验，不报告性能验收通过。

仪器包括独立位移尺/传感器、外部角度测量、逻辑分析仪或示波器；电气测试仪器按实际接口选择。所有仪器连接、接地和量程须先依据实际电气图核对，不能引入未经确认的共地。

初次波形能力鉴定在隔离的、明确授权的测试环境进行，生产运行配置保持禁止ARM。使用与已确认电气接口匹配的独立资格鉴定步骤/厂家工具核实波形后，才给正式配置填写 `waveform_hil_verified` 及记录编号；不能为了绕过能力门控先在生产配置中谎报已验证。软件流程、参考设置和控制命令按最终 [用户指南](USER_GUIDE.md) 执行，不调用legacy顶层脚本。

## H01：身份、接线与低速标定

| 项目 | 操作与观测 | 必须保留的证据 | 当前状态 |
|---|---|---|---|
| 设备与接线 | 断电逐线核验铭牌、端子、供电、转换器与信号电平 | 设备清单、手册版本、针脚表、照片、导通记录 | NOT_RUN |
| 舵机身份 | 输出禁止下读取实际型号/固件；与白名单配置比较；错误型号必须拒绝 | 原始读回、连接epoch、错误事件 | NOT_RUN |
| 模式事务 | 逐步核对扭矩禁止、速度模式、限制、watchdog和零速；人为造成一步失败时不使能 | 每步通信/设备结果、读回、最终禁止状态 | NOT_RUN |
| 遗留输出 | 按允许的实验条件制造遗留非零目标，重启/重连应先禁止并处理残留 | 示波/速度记录、启动日志、无自动动作证据 | NOT_RUN |
| 外部编码器 | 核对位宽/符号/字节序/回绕；静止重复读数仍有新seq；断开后无有效假零 | 原始帧、时间分布、计数与独立测量 | NOT_RUN |
| 推进方向/比例 | 经批准小速度和有限位移，插入为正；多点往返、有载/无载 | 舵机圈数、原始计数、独立位移、拟合残差 | NOT_RUN |
| 旋转方向/比例 | 固定观察方向，核对正方向、细分拨码、每圈脉冲和传动比 | 拨码照片、边沿计数、外部角度 | NOT_RUN |
| 参考与限位 | 静止设置软件参考；参考变更拒绝旧命令；过程制动在允许范围内 | reference_id、轨迹、边界距离与停止证据 | NOT_RUN |

不要因为目录名包含XM430、DM542或旧代码写了6400、17/30就通过身份/比例检查。`configured_identity_only` 的编码器身份状态必须如实记录，不伪造设备自报型号。没有原点器件不验证“自动机械回零”。

## H02：波形、生命周期与开环角度

1. 在已确认接口和允许转动条件下，外部仪器观察PUL、DIR及实际存在的EN；记录有效沿、最小高/低时间、方向建立/保持、端口电平。
2. 执行有限正向、反向波形，核对请求段ID、实际边沿数、后端wave_id/epoch、运行及完成事件。正反向都要测，换向不能在未满足建立时间时发第一个有效沿。
3. 检查段的整体时间预算，包括DIR前后空档。组合段连接处测连续性与速度变化；不能凭“各段都accepted”宣称无间断或精确同步。
4. 对完整段验证边沿总数；同时用外部仪器测机械角度，分开报告脉冲估计误差和实际角度误差。失步可以导致二者不同，不把开环估算写成实测角度。
5. 在段起始、中间、结束附近分别请求取消。记录最后有效沿、停止请求/应答、daemon idle和机械余运动。中止后实际已发计数不可证明时，软件必须使角度估计无效并拒绝依赖该参考的定位。
6. 制造不同wave_id替换、连接中断、daemon重启和进程退出（仅在实验范围内），检查旧epoch/代次不再结算；未知结果不得上报成功。
7. 用更短段及增加CPU/日志/DDS负载测轮询抖动。若没能观察完整运行生命周期，软件应报告估计无效；修正段长/后端能力后重测，不放宽为按时间猜计数。
8. 记录daemon的服务账户、socket访问限制、本机flock和其它客户端禁止规则。本机advisory锁不能排除任意第三方直接连接daemon；未建立独占访问，不启用完整段条件计数模式。

H02通过并不证明无机械失步，也不证明两个轴同时启动。当前后端无软件EN输出；若实机依赖EN或独立禁止才能满足停止预算，应先实现并验证对应接口，再宣称该运行模式合格。

## H03：控制、停止与故障性能

先填目标值，再采样。至少测下表；报告最大值及分布，不只给平均值。

| 场景 | 核对内容 | 关键失效判据 | 当前状态 |
|---|---|---|---|
| 单轴及双轴定位 | 位置误差、超调、速度/加速度、到位驻留 | 轨迹未完或反馈/速度无效时提前成功 | NOT_RUN |
| Jog/deadman | 按住/释放、手柄拔出、输入异常 | 节点仍活跃却续发旧速度 | NOT_RUN |
| 正常STOP/取消 | 请求、调度、最后输出、零速证据、机械停止 | 仅写零速成功就报告已停止 | NOT_RUN |
| 编码器失效 | 断开、CRC错误、冻结与长间隔 | 用缓存续期、用假零闭环、反馈失效后继续无限运动 | NOT_RUN |
| 控制任务冻结 | 遥测保持活跃时冻结控制任务 | I/O端因仍能读包而维持旧输出 | NOT_RUN |
| 协调器/上位机失联 | 关闭源端/网络，执行租约到期 | 网关或设备替失联源无限续租 | NOT_RUN |
| 总线/SDK错误 | 阻塞/写失败、状态无法确认 | 无期限等待、停止未知却报告成功 | NOT_RUN |
| 进程/daemon故障 | 在授权条件下停止进程或重启daemon | 没有能力证据却声称软件可抵御整进程/OS冻结 | NOT_RUN |
| 重启与恢复 | 新epoch、DISARMED、旧目标拒绝 | 自动ARM、自动设零或续跑历史任务 | NOT_RUN |
| 满负载 | 慢盘、满盘、CPU与DDS负载、慢订阅 | 控制等待写盘/发布、日志无界增长 | NOT_RUN |

停止预算按实测分解：检测 + 本地许可到期/调度 + 在途事务 + 硬件缓冲 + 执行器/机械响应。任一项无上界就不能声称确定的最坏停止时间。DYNAMIXEL watchdog观察总线指令，遥测也可能维持其活跃；需验证控制停止失败时不会继续普通轮询保留旧速度。参考 [官方Bus Watchdog语义](https://emanual.robotis.com/docs/en/dxl/x/xm430-w350/#bus-watchdog98)。

HOLD继续输出和监督，不等于停止。结束保持、反馈过期或租约到期都必须进入约定停止/禁止流程。GCA故障联动与Windows磁驱动器联合验收属于系统扩展，当前GCA-only的通过不替代跨端电流验收。
